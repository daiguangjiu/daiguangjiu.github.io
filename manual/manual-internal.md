## 🔑 第二章 账号注册与基础搭建

### 2.1 注册流程（标准操作）

1. 下载闲鱼APP：通过官方应用商店下载，勿用第三方修改版。
2. 注册/登录：使用手机号注册淘宝账号 → 自动关联支付宝。已有淘宝/支付宝账号可直接登录。
3. 绑定支付宝：进入「我的」→「设置」→「支付设置」→ 绑定已实名认证的支付宝账号。
4. 设置头像和昵称：头像用真实/半真实照片（增加信任感），昵称简洁易记，建议与经营类目相关。
5. 完善个人资料：填写个人简介、所在城市、性别等基础信息。简介中可自然嵌入经营方向。
一个身份证可实名认证 3个支付宝账号，对应可开 3个闲鱼账号。但需配合3个不同手机号，且遵守"一机一卡一号"原则。

### 2.2 实名认证

| 认证类型 | 要求 | 路径 |
| --- | --- | --- |
| 基础实名 | 身份证 + 人脸识别 | 我的 → 设置 → 账号与安全 → 实名认证 |
| 支付宝实名 | 需与闲鱼账号绑定的支付宝已完成实名 | 支付宝APP → 我的 → 设置 → 账号与安全 |
| 企业蓝V认证 | 营业执照 + 法人身份信息 | 需通过代理商/官方渠道提交 |

建议优先完成支付宝高级实名认证（绑定银行卡），可提升账号权重和交易额度。

### 2.3 芝麻信用分与闲气值

| 指标 | 满分 | 合格线 | 影响 |
| --- | --- | --- | --- |
| 芝麻信用分 | 950 | ≥ 650（优秀≥700） | 影响商品排名权重、买家信任度、超级擦亮投放资格 |
| 闲气值 | 100 | ≥ 80（鱼小铺门槛） | 低于80无法开通鱼小铺；低于60限制发布商品 |

提升芝麻信用分：完善学历/职业信息、按时还花呗/借呗、多使用支付宝线下支付、保持稳定收货地址。

### 2.4 认证招商与经营资质上传

「认证招商」是闲鱼为经营性卖家提供的资质认证入口。完成经营资质上传后，账号将获得企业/个体工商户标识，解锁更多经营工具和流量权益。对于月流水超5万或经营品牌商品的卖家，建议尽早完成认证。

#### 2.4.1 认证招商入口位置

进入路径：闲鱼APP → 我的 → 认证招商（或 设置 → 认证招商）

在「认证招商」页面中，可以看到以下模块：

- 经营资质 — 上传营业执照，完成企业/个体户认证
- 品牌资质 — 品牌授权书上传（经营品牌商品时需要）
- 行业资质 — 特定行业许可（如食品经营许可证等）
#### 2.4.2 经营资质类型与所需材料

| 资质类型 | 适用对象 | 需上传材料 |
| --- | --- | --- |
| 个人认证 | 个人卖家（默认） | 身份证 + 支付宝实名即可，无需额外操作 |
| 个体工商户 | 有个体营业执照的卖家 | 营业执照原件照片/彩色扫描件 + 法人身份证正反面 |
| 企业认证 | 有公司营业执照的商家 | 营业执照 + 法人身份证 + 对公银行账户（可选）+ 企业支付宝 |

#### 2.4.3 经营资质上传操作步骤（6步）

1. 进入认证招商：打开闲鱼APP → 点击右下角「我的」→ 找到「认证招商」入口（或在「设置」中查找）。
2. 选择经营资质：进入「认证招商」页面后，点击「经营资质」选项。
3. 点击立即开通：在经营资质页面，点击「立即去开通」按钮。
4. 选择资质类型：根据实际情况选择「个体工商户」或「企业」，然后点击「下一步」。
5. 阅读并确认承诺函：仔细阅读《确认函》内容，确认无误后点击「下一步」。
6. 填写信息并提交：在「新增认证」页面，逐项填写对应信息（企业名称、统一社会信用代码、法人信息等），上传营业执照照片和身份证照片，点击「提交」等待审核。
#### 2.4.4 审核要点与避坑指南

| 审核要点 | 具体要求 | 常见被拒原因 |
| --- | --- | --- |
| 执照有效期 | 剩余有效期最好大于6个月 | 执照已过期或临近过期 |
| 照片质量 | 清晰完整、无反光、无水印、四角完整 | 照片模糊、反光严重、边缘裁剪不完整 |
| 信息一致性 | 执照法人 = 闲鱼实名认证人 = 支付宝实名认证人 | 法人信息与账号实名不一致 |
| 经营范围 | 执照经营范围需包含销售相关类目 | 经营范围与在售商品不符 |
| 填写准确性 | 填写信息必须与执照完全一致（包括标点符号） | 公司名漏字、信用代码错位 |

⚠️ 审核注意事项：

  • 审核周期：通常 3-5个工作日，高峰期可能延长至7天

  • 审核通过后，建议第二天再上架商品，更稳妥

  • 审核失败可重新提交，注意查看拒绝原因中的具体说明

  • 认证免费，无需支付任何费用（警惕"代认证"收费骗局）

#### 2.4.5 认证后的权益变化

| 权益 | 未认证（个人） | 已认证（企业/个体户） |
| --- | --- | --- |
| 账号标识 | 无特殊标识 | 显示「企业」或「个体户」标签，买家信任度提升 |
| 商品上限 | 普通用户50个，鱼小铺500个 | 上限更高，适合大批量经营 |
| 流量扶持 | 标准流量 | 搜索排名加权，新品有额外曝光 |
| 营销工具 | 基础功能 | 可申请超级擦亮高级功能、线索收集页等 |
| 平台活动 | 部分活动受限 | 优先参与官方大促、品类专场活动 |
| 开票能力 | 不支持 | 可对接企业支付宝开票功能 |

建议：如果月流水稳定在5万以上，或经营品牌商品需要向买家展示正规资质，强烈建议完成认证招商。认证不仅是合规要求，更是获取平台流量倾斜的「通行证」。

## 🏪 第三章 鱼小铺开通全流程

### 3.1 什么是鱼小铺？

鱼小铺是闲鱼官方推出的专业卖家工具，开通后可获得：

- 专属店铺页面（自定义封面、分类展示）
- 商品上限提升至 500个（普通用户仅50个）
- 数据看板（曝光量、浏览量、转化率等）
- 付费推广权限（超级擦亮）
- 优先参与平台活动
### 3.1 开通前置条件

| 条件 | 具体要求 | 检查方式 |
| --- | --- | --- |
| 账号状态 | 无违规记录，正常状态 | 我的 → 安全中心 |
| 闲气值 | ≥ 80 分 | 我的 → 闲气值 |
| 芝麻信用 | 建议 ≥ 650 分 | 我的 → 芝麻信用 |
| 实名认证 | 已完成支付宝实名认证 | 设置 → 账号与安全 |
| 发布商品数 | 建议累计发布 ≥ 50 个 | 我的 → 我发布的 |
| 交易活跃度 | 近30天有稳定买卖记录 | 我的 → 交易记录 |

### 3.2 快速开通实操方法（10-16天）

以下为经过验证的加速方法，核心逻辑是向平台证明你是"活跃的专业卖家"。

#### 第一阶段：基础活跃（第1-3天）

1. 每日签到领闲鱼币，完成「我的」页面全部日常任务（3-5个即可）。
2. 每日保持 2小时以上在线，浏览推荐页、点赞、关注其他卖家。
3. 在「会玩」社区发布2-3条帖子，内容与你的经营类目相关。
4. 完善个人资料：头像、简介、背景图全部设置到位。
#### 第二阶段：买卖养号（第4-10天）

1. 每天上架10个商品，间隔20分钟发布一个，分散到全天。
2. 每天完成5笔购买：在闲鱼购买虚拟商品（PPT模板、教程笔记等，单价0.1-1元），买不同店铺的商品。
3. 每笔确认收货后写10字以上好评，并关注卖家后再评价。
4. 每天卖出商品：上架虚拟商品（如教程资料），定价0.1元包邮，用闲鱼币推广+加入公益捐赠。有人拍下后发网盘链接，选「无需寄件」发货。
5. 下架曝光差的商品，优化后重新上架。
#### 第三阶段：冲刺触发（第10-16天）

1. 保持每日上架+买卖节奏不中断。
2. 积极回复买家咨询（10分钟内回复加分）。
3. 主动确认收货 + 给买家好评。
4. 累计发布商品达到50个以上后，继续发布以刺激系统。
不要大量上架一模一样（同标题、同图片、同文案）的商品，会被判定为重复铺货违规。图片和文案必须做差异化调整。

## 📈 第七章 流量获取与付费投放

### 7.1 自然流量获取策略

2026年重大变化：免费自然流量分配逻辑已被彻底重构。免费擦亮权重断崖式下降（从过去几百次曝光锐减到几十甚至个位数），搜索和推荐流量改为「优质优先」——只有持续成交、好评率高、转化率好的商品才能获得免费流量。平台引入了「宝贝质量分」体系，低价/无动态/回复慢/退货率高的账号极难获得免费曝光。免费流量池没变大，分水的人多了，平台又把大部分水引到了付费管道。

| 策略 | 操作 | 预期效果 | 2026现状 |
| --- | --- | --- | --- |
| 每日擦亮 | 5:00-7:00 手动擦亮宝贝（每日一次免费） | 曝光+30%-50% | 权重断崖下降，仅几十次曝光 |
| 闲鱼币推广 | 用闲鱼币兑换推广位（每日签到获取） | 适合测款，零成本 | 效果有限，作为补充 |

| 鱼塘互动 | 加入相关鱼塘，发布商品到鱼塘 | 精准人群曝光 | 稳定，垂直流量 |
| 拍下立减+公益 | 设置拍下立减 + 加入公益捐赠 | 转化率+15%-25% | 有效，提升质量分 |

### 7.2 超级擦亮投放指南

超级擦亮是闲鱼官方的付费推广工具。2026年升级后，它不再是简单的"花钱擦一下"，而是精准流量匹配系统——系统根据商品标题、属性、历史成交数据，主动将商品推送给近期浏览/搜索/收藏过类似商品的高意向买家。本质上是用预算撬动数据资产，投放沉淀的点击、咨询、收藏数据会反过来拉升商品质量分，未来自然流量也会上升。

核心认知：超级擦亮不是"花钱买一天热闹"，而是用一笔小预算撬动一笔数据资产。配合主图、前3秒视频和文案持续优化——流量进来了承接不住，系统会判定你「不值得继续推」，后续成本越来越高。

#### 7.2.1 投放红线（必须遵守）

- 单账号 ≤ 3个擦亮计划（超出曝光降50%）
- 擦亮24小时内改价超2次或修改主图 → 曝光失效

| 高退货率类目 | 退货不退服务费，双重损失 |
| 成熟爆款 | AI改动可能破坏已稳定的人群标签和搜索权重 |

#### 🔧 实操五步法

1. 底价定价留缓冲：底价 = 成本价 + 服务费 + 运费 + 至少15%利润缓冲。算法会向下调价，底价定太低可能亏本。
2. 原始文案标准化：在提报前完整标注成色、瑕疵、售后边界、发货时效。AI在此基础上优化，减少描述偏差风险。
3. 库存分批提报：不要一次性把所有库存提交无忧卖。分批次少量提报，降低滞销和降价风险。
4. 小批量灰度测试：先用3-5个商品测试AI调价逻辑、客服话术、图文修改规律，验证后再批量上线。
5. 定期复盘调整：每周检查无忧卖商品的成交价、退货率、客服评价，发现异常及时关闭托管。
#### 📊 无忧卖 vs 自主运营对比

| 维度 | 无忧卖托管 | 自主运营 |
| --- | --- | --- |
| 时间投入 | 低（AI接管日常运营） | 高（需全天候运营） |
| 定价控制 | 弱（AI动态调价） | 强（完全自主定价） |
| 流量获取 | 有平台流量加权 | 靠自然流量+付费推广 |
| 客服质量 | AI 24小时在线，但可能答非所问 | 人工回复，质量可控 |
| 商品描述 | AI自动优化，可能失真 | 完全可控，真实准确 |
| 成本 | 3.5%-10%服务费 | 人力+时间成本 |
| 风险 | AI行为归责卖家，不可控风险高 | 风险完全自控 |

### 14.7 关键注意事项

⚠️ 三条底线：

  1. 底价≠售价：底价是下限，不是建议售价。务必留足利润空间。

  2. 退货损失翻倍：退货不仅损失运费，服务费也不退，薄利商品尤其谨慎。

  3. AI言论你买单：AI客服做出的任何承诺，法律责任全归卖家。

## 🚨 第十一章 风控管理与风险排查

闲鱼风控已从"人工审核"升级为"AI+人工"双轨制。矩阵运营和批量操作一旦触发风控，轻则限制登录，重则永久封禁。本章基于实际违规案例，建立预防-识别-处置-复盘全流程。

### 9.1 风控预防体系

风控不是事后补救，而是贯穿账号全生命周期的管理。核心原则：环境隔离、行为真实、节奏自然、证据完整。

| 层级 | 防控点 | 执行标准 |
| --- | --- | --- |
| 设备层 | 一机一卡一号 | 每账号独立设备；不频繁切换设备登录；不安装多开/分身软件 |
| 网络层 | 独立网络 | 多账号使用不同WiFi或手机流量；禁止同WiFi下登录超过1个账号 |
| 注册层 | 真实注册 | 实名/实人认证；避免批量注册、虚拟号段、接码平台注册 |
| 行为层 | 自然养号 | 每日在线≥2小时；模拟真实用户浏览、点赞、评论 |
| 交易层 | 真实交易 | 避免同一账号高频买卖给相同对象；拒绝刷单、虚假发货 |
| 内容层 | 合规发布 | 禁售清单对照；不使用违禁词；不发布站外联系方式 |
| 证据层 | 留痕备查 | 发货视频、聊天记录、物流单号保存至少3个月 |

#### 环境隔离检查清单（每日执行）

- 每个账号是否使用独立设备？
- 每个账号是否使用独立网络（WiFi/流量）？
- 是否关闭了手机的多开/分身/虚拟机？
- 账号是否完成实名+实人认证？
- 今日是否保持2小时以上自然在线？
- 是否有多个账号互相点赞/交易/转发？
- 是否使用同一收货地址发货？
### 9.2 常见风险类型与识别

根据官方规则及实际案例，以下风险类型最高发：

| 风险类型 | 触发原因 | 页面提示 | 后果 |
| --- | --- | --- | --- |
| 不当注册 | 批量注册、虚拟号、同一设备注册多号、异常IP | "存在1条限制登录风险！需完成实名认证解除风险" | 限制登录，需完成认证；多次触发可能永久封禁 |
| 不当使用账户 | 租借/买卖账号、同一账号多人使用、异常登录地 | "账号被永久限制使用，请使用其他手机号重新注册" | 永久限制登录，无法解封 |
| 危及交易安全 | 虚假发货、诱导定金/预付款、诈骗欺诈 | 安全中心显示"危及交易安全" | 扣100分，通知支付宝管控 |

### 9.3 风险出现后排查与处置

当收到风控提示后，按以下流程处理，避免情绪化操作导致二次违规：

#### 第一步：确认风险类型

| 提示文案 | 对应风险类型 | 可逆性 |
| --- | --- | --- |
| "需完成实名认证解除风险" | 不当注册 | 可逆（完成认证后可能恢复） |
| "账号被永久限制使用，请使用其他手机号重新注册" | 不当使用账户 | 不可逆 |
| "存在危及交易安全" | 危及交易安全 | 视情节，可申诉 |
| 商品被下架 + 扣分 | 发布违禁/风险信息 | 可申诉 |

#### 第二步：定位触发原因

1. 检查近7天操作记录：是否批量注册、多账号共用网络、同一设备切换账号、异常IP登录。
2. 检查交易行为：是否高频买卖给同一对象、是否有买家投诉、是否有虚假发货。
3. 检查商品内容：是否误触禁售品类、是否使用违禁词、是否引导站外。
4. 检查矩阵关联：同一身份证/手机号/设备/网络下其他账号是否同时异常。
5. 检查登录环境：是否使用了VPN/代理IP、是否异地登录频繁。
#### 第三步：分类型处置

| 风险类型 | 处置动作 |
| --- | --- |
| 不当注册 | 立即完成实名认证+实人认证；暂停该设备3天内的注册行为；检查该设备是否登录其他账号 |
| 不当使用账户 | 该账号弃用，不可再尝试登录；检查同设备/同网络/同身份证下其他账号是否被关联；隔离所有相关账号 |
| 危及交易安全 | 停止可疑交易；整理发货凭证、聊天记录；72小时内提交申诉 |
| 发布违禁信息 | 删除违规商品；对照禁售清单整改；保留申诉证据 |
| 关联风控 | 立即隔离所有账号（换设备、换网络、换手机号）；停止矩阵操作7-15天 |

#### 第四步：复盘与规避

- 建立该账号的完整"风控档案"：设备、网络、手机号、操作时间线
- 标记高风险设备和网络，后续不再使用
- 同批次注册的账号全部重点观察7天
- 调整养号节奏，降低操作频率
### 9.4 矩阵关联风控与隔离策略

官方规则明确：若一个账号因骗取财物、售假、扰乱秩序等被严重处罚，闲鱼可对同一实际控制人名下的其他账号一并处置。矩阵运营必须做好隔离。

| 隔离维度 | 最低标准 | 推荐标准 |
| --- | --- | --- |
| 设备 | 一账号一设备 | 一账号一手机，不使用任何多开/分身 |
| 网络 | 不同WiFi | 每账号独立手机流量，或每账号独立宽带 |
| 手机号 | 一账号一手机号 | 不同运营商号段，避免连号/虚拟号 |
| 身份证 | 一身份证最多3个支付宝/闲鱼号 | 核心账号使用不同身份证主体 |
| 支付宝 | 一账号绑定一支付宝 | 核心账号使用独立支付宝，避免资金关联 |
| 收货地址 | 不共用同一地址 | 不同城市/区域，地址有明显差异 |
| 商品 | 不互相转发/点赞 | 不同账号经营不同类目，避免同质化 |
| 交易 | 不互相买卖 | 无任何交易关联，不共用同一个买家 |

#### 矩阵风控巡检表

| 检查项 | 频率 | 正常 | 异常 |
| --- | --- | --- | --- |
| 各账号安全中心状态 | 每日 | 无风险提示 | 立即隔离+标记 |
| 各账号闲气值 | 每日 | ≥80 | 低于80停止发布，养号 |
| 多账号是否共用网络/设备 | 每周 | 完全隔离 | 拆分设备和网络 |
| 矩阵账号交易关联 | 每周 | 无互相交易 | 停止关联交易 |
| 违规账号关联影响 | 每次封号后 | 其他账号正常 | 全面隔离+换主体 |

#### 风控红线口诀

一机一卡一号，不共网不互点不互买。

  实名实人要一致，批量注册必被封。

  异常登录先停用，关联账号要隔离。

  发货凭证留三月，申诉才能有理据。

## 📜 第十五章 官方规则精要

本章内容提炼自闲鱼官方规则中心（https://h5.m.goofish.com/wow/moyu/moyu-project/doc/pages/v3Lv4OO6VbJS），涵盖29项现行规则。建议定期对照官方规则中心检查更新。规则中心路径：闲鱼APP → 我的 → 设置 → 闲鱼公约。

### 13.1 卖方软件服务费收费规则

这是所有闲鱼卖家必须了解的核心规则，直接影响利润核算。

| 费用类型 | 收费门槛 | 费率 | 计算基数 |
| --- | --- | --- | --- |
| 基础软件服务费 | 所有成交订单（无门槛） | 0.6% | 每笔订单成交额 |
| 软件服务费-基础门槛 | 当月累计成交＞10单 且 累计金额＞10,000元 | 1%（超出门槛部分） | 超出门槛的每笔订单成交额 |
| 软件服务费-品类门槛（手机） | 当年手机品类累计成交＞6笔 | 1%（超出门槛部分） | 超出门槛的手机品类每笔订单成交额 |
| 软件服务费-鱼小铺 | 开通鱼小铺工具服务的卖方 | 1%（所有订单） | 每笔订单成交额 |

#### 关键要点：

- 总费率上限：同一笔订单最多收取 0.6%（基础）+ 1%（软件服务费）= 合计 1.6%
- 基础门槛 vs 品类门槛：同一订单同时满足时，仅按品类门槛收取（不重复收）
- 鱼小铺卖家：不再享受"基础门槛"和"品类门槛"的优惠政策，每笔订单都收取1%+0.6%
- 退款不退费：成交后发生退款，已划扣的软件服务费不做退还
- 扣款方式：由支付服务商从买家支付的订单款项中实时划扣
- 手机品类统计：从每年1月1日起统计交易成功订单，超出6笔后开始收费
- 规则生效：2024年9月1日起实施基础软件服务费；2026年4月18日最新修订
运营启示：对于月销超1万或手机品类活跃卖家，需将1.6%的服务费纳入定价成本核算。鱼小铺卖家需特别注意——一旦开通，每单都收费，小额多单模式成本更高。

### 13.2 经营性行为界定与管理规范（2026年6月1日生效）

此为新规，标志着闲鱼正式区分"个人卖家"和"经营性卖家"，对团队矩阵运营影响重大。

#### 经营性卖家认定标准（满足任一即可能被认定）：

| 认定方式 | 标准 |
| --- | --- |
| 主动申报 | 已取得营业执照、许可证等经营资质，或公示自我经营声明 |
| 行为判定 | 使用"一手货源""固定货源""有售后""七天无理由退货""多库存""多规格"等经营性描述，且同时满足：① 在售物品＞30件且品类＜3类② 同一型号频繁售出5次以上③ 年交易≥104笔，每月至少3笔④ 年销售额＞10万元 |
| 特殊豁免 | 收藏品/奢侈品、潮玩/潮鞋/数码/乐器、搬家出清、明星网红闲置等场景，不直接认定为经营行为，综合判定 |

#### 被认定为经营性卖家后的义务：

1. 依法登记：办理市场主体登记（符合豁免情形除外）
2. 信息登记：如实登记身份、经营地址、联系方式、行政许可等（变更后3个工作日内更新）
3. 信息公示：个人主页显著位置公示营业执照（或身份信息）、经营地址、联系方式等
4. 商品信息披露：如实披露品牌、型号、现状、维修记录、瑕疵等
5. 经营者义务：履行"七日无理由退货"、质量退换货、售后义务
矩阵运营注意：经营性认定 + 一机一卡一号原则 = 矩阵账号中高销量账号必须合规经营主体化。建议提前为旗舰号准备营业执照，垂直号控制在认定门槛以下。

### 13.4 七天无理由退货规范

| 分类 | 商品类型 | 说明 |
| --- | --- | --- |
| 不支持 | 定制类、鲜活易腐类、在线下载/拆封的数字化商品、报纸期刊、服务类、竞拍商品、人体用药 | 绝对不可退货 |
| 卖家可选 | 激活后价值贬损大的商品（VR头盔等）、黄金、拆封后影响安全健康的（食品/保健品/贴身用品/成人用品）、所有品类非全新商品 | 卖家自愿开通 |

#### 关键细节：

- 七天计算：签收次日零时起算，满168小时（7天）

- 特殊品类：手机类未激活、食品化妆品密封包装未拆封、鞋类防盗扣未剪
- 经营性卖家：个人主页展示"商"标识，发布全新商品强制支持七天无理由

#### D.6 每日数据复盘流程（10分钟）

1. 录入数据（2分钟）：在决策系统中录入当日花费、曝光、点击、咨询、成交、退货数据。
2. 检查预警（2分钟）：对照D.3监控指标，标红异常项（ROAS不达标/退货率超标/CTR过低等）。
3. 决策动作（3分钟）：关停不达标计划 → 递增优质计划预算 → 替换低CTR素材 → 调整出价。
4. 记录笔记（2分钟）：简要记录当日关键决策和原因（为什么关/为什么加/为什么换）。
5. 每周校准（1分钟）：积累7天真实数据后，更新决策系统中的漏斗系数（CPC/CTR/咨询率/成交率），让模型越来越准。
关键原则：测款期重在「快」——多条计划快速试错淘汰；放量期重在「稳」——聚焦Top计划，严控ROAS和退货率；维稳期重在「收」——降出价、精选时段、集中预算清仓。每个阶段关键指标达标后再进下一阶段，不要跳步。

### E. 固定提醒

1. 资料归档运营资料库：所有投放数据、复盘笔记、素材素材迭代记录，统一归档到团队共享文档/网盘，便于后续复盘和新人培训。
2. 待办问题创建跟进事项：每日复盘发现的异常（如退货率飙升、某素材CTR骤降），立即在团队协作工具中创建待办事项，指定责任人+截止时间，确保问题不遗漏、有闭环。
